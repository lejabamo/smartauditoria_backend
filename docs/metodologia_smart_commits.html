Trazabilidad Mediante Smart Commits

Durante el desarrollo de SmartAuditorIA, se ha implementado un flujo de trazabilidad técnica que garantiza la vinculación directa entre el código fuente y las Historias de Usuario (HU). Esta metodología permite evidenciar el cumplimiento de requerimientos de forma automatizada y auditable.
Fase 1: Etiquetado Semántico

Cada cambio en el código debe incluir el ID de la HU correspondiente en Jira, permitiendo el despliegue de evidencia forense.

git commit -m "SCRUM-14: Implementacion de dashboard estratégico."
Fase 2: Orquestación MLOps

El agente DevOps detecta los prefijos y actualiza el panel de "Development" en Jira, vinculando commits, ramas y pull requests.

Beneficios de la Metodología

La implementación de esta práctica ágil reporta los siguientes beneficios para el proyecto:

  • Gobernanza de Datos: Historial completo de cambios por cada control de seguridad ISO 27001 implementado.
  • Visibilidad Gerencial: El Product Owner puede ver el avance real del código sin salir de Jira.
  • Auditoría Automatizada: Generación de reportes de evidencia para la sustentación final ante el jurado.
