Resumen Ejecutivo

Visión general del proyecto y objetivos alcanzados.

SmartAuditorIA es una solución integral para la gestión de riesgos bajo normativas ISO 27001/27005, que utiliza agentes inteligentes para automatizar la auditoría y proporcionar sugerencias de control en tiempo real.

Objetivo

Digitalizar y profesionalizar el proceso de gestión de activos y riesgos, integrando un motor experto que asista al auditor institucional.

Logros Clave

  • Arquitectura modular escalable.
  • Motor RAG funcional con normativa ISO.
  • Wizard interactivo de evaluación 5x5.
  • Trazabilidad total GitHub ↔ Jira.

  • Frontend: React 18, Material UI, Vite.
  • Backend: FastAPI / Flask, SQLAlchemy.
  • IA Engine: LangChain, OpenAI, ChromaDB.
  • DevOps: Docker Compose, GitHub Actions.
