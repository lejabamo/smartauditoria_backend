Sistema de Gestión de Seguridad y Riesgos de Información (SGSRI)

Plataforma de gobernanza y auditoría automatizada de activos de información con asistencia de Inteligencia Artificial (RAG/CAG), alineada con los marcos obligatorios DAFP V7, MIPG y las normas ISO/IEC 27001 e ISO 27005:2022.

Ecosistema de Repositorios GitHub

Arquitectura desacoplada en tres repositorios oficiales con código fuente, pruebas automatizadas y control de versiones bajo metodología Git:

Frontend SPA

smartauditoria_frontend

Interfaz de usuario reactiva construida en React 18, TypeScript, Vite y Material UI. Implementa el Wizard guiado de auditoría, la matriz 5x5 de riesgos y el Dashboard ejecutivo.

Stack: React 18 · TypeScript · Vite Rama: gh-pages / main
Ver Repositorio Frontend
Backend API REST

smartauditoria_backend

Servicios RESTful en Python Flask con SQLAlchemy y base de datos MariaDB. Gestiona la autenticación JWT, control de acceso RBAC, CRUD de activos y cálculo de criticidad CIA.

Stack: Python 3.11 · Flask · MariaDB Pruebas: Pytest E2E
Ver Repositorio Backend
Motor Inteligente

smartauditoria_engine

Microservicio de inteligencia artificial en FastAPI. Orquesta el pipeline RAG para sugerencia asistida de controles ISO/IEC 27002:2022 y justificaciones contextuales técnicas.

Stack: FastAPI · ChromaDB · RAG Despliegue: VPS Oracle Cloud
Ver Repositorio Engine IA

Product Backlog y Gestión en Jira

Planificación y trazabilidad de los requerimientos y compromisos del curso en Jira Software:

Panel de Control SCRUM en Jira

El proyecto se encuentra registrado y estructurado en Jira Software bajo la clave SCRUM, con épicas orientadas a la consolidación de la gobernanza de activos, controles de auditoría y despliegue en la nube.

Nota técnica de integración: El seguimiento del backlog se realiza directamente en Jira Software. Actualmente no se dispone de sincronización automática mediante webhooks hacia los repositorios de GitHub en esta fase; la trazabilidad de historias se gestiona de forma manual y verificable sobre el tablero.
