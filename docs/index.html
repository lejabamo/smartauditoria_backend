CRITERIO 1: APLICACIÓN PRÁCTICAS ÁGILES

Metodología y Dinámica del Equipo

El proyecto ha operado bajo un marco ágil riguroso adaptado para la integración de Inteligencia Artificial. Se han definido claramente los roles, ceremonias (sprints, validaciones cruzadas) y la arquitectura tecnológica que sostiene el producto.

Roles y Ceremonias

  • Product Owner: Liderazgo en la definición funcional de gestión ISO 27001.
  • Ingenieros / Agentes: Responsables de la ejecución full-stack (UI, API, Engine).
  • Sprint Planning: Iteraciones de 2 semanas trazadas estrictamente en Jira.
  • Definition of Done (DoD): Código compilado, probado y pusheado al repositorio de GitHub con Hash visible.

Stack Tecnológico

  • Frontend UI: React 18, Vite, Material UI (Alta disponibilidad).
  • Backend Core: Python 3.11, FastAPI, ORM SQLAlchemy + MariaDB.
  • AI Engine (RAG): OpenAI Models, ChromaDB (Vector Search).
  • Orquestación: Docker Compose y segregación multirepositorio por módulos.
DISEÑO Y ESTRUCTURACIÓN

Estructura Arquitectural de los Módulos

El sistema se concibe como una plataforma distribuida en microservicios, desacoplando la interfaz de usuario, la lógica de negocio y el motor experto (IA). Esta orquestación garantiza la escalabilidad en ambientes de nube, segmentando las responsabilidades operativas en paquetes independientes.
